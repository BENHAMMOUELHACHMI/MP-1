# Site CPGE MP — Physique & Chimie

Site pédagogique responsive pour PC, tablette et téléphone.

## Mise en ligne avec GitHub Pages
1. Créer un dépôt public nommé `cpge-mp`.
2. Déposer `index.html` et le dossier `pdf`.
3. Aller dans **Settings → Pages**.
4. Choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`.
5. Enregistrer.

## Ajouter un cours PDF
Déposer le PDF dans `pdf/physique/` ou `pdf/chimie/`, puis modifier le lien correspondant dans `index.html`.

Les fichiers PDF inclus ici sont des emplacements : remplace-les par tes propres documents.
